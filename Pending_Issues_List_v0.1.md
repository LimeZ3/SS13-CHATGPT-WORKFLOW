# SS13 Illustration – Master Issue List
*(Collect all recurring hiccups before we design fixes)*

- **Style Preset Ignored**  
  - “Slick Anime” or “Line Art” requested → Bold-Comic generated.

- **HUD-type Glasses Rendering Errors**  
  - Security HUDSunglasses show as plain black shades or wrong-color glare.  
  - Sunscanners display white text or no orange strip.

- **ID Badge Problems**  
  - Text garbled or badge rendered as flat card instead of grey cartridge.  
  - No-text rule sometimes skipped; Cyrillic still printed.

- **Anthro Fur vs. Hair Confusion**  
  - Vulpkanin / Tajaran white muzzle read as “skeleton mask.”  
  - Separate fur-color and hair-color often merged or lost.

- **Weapon / Sidearm Missing**  
  - Disabler, baton, etc., listed in shift-click but absent in art.

- **Satchel / Backpack Visibility**  
  - Back-worn bags frequently omitted (low-priority cosmetic).

- **Blood-Stained Items Render Clean**  
  - Cloth handwraps or uniforms lose the blood-spatter detail.

- **Armor vs. Cloak Layering**  
  - Cloak hides security armor; armor cross miscolored red (reads as Medical).

- **Combat Glove Color Drift**  
  - Bright red combat gloves appear black or grey.

- **Reference Docs Lazy-Load**  
  - Some runs skip loading cheat-sheets unless Step-0 “open” calls fire.

- **Prompt Length Trade-offs**  
  - >180-word prompts dilute detail; <60 words drop essential traits.

- **Sprite Angle Coverage**  
  - Missing rear view causes lost tails, backpacks, coat tails.

- **Background Department Palette**  
  - Security corridor rendered teal; departmental color cues off.

- **Species Anatomy Omissions**  
  - Tails absent; Unathi head crests simplified; Vox beak flattened.

- **Cheat-Sheet Expansion Needed**  
  - Missing entries: security beret, Krav Maga red gloves, disabler sidearm.
