## Global Rule: Flavor Text Precedence
**Asset hierarchy:**  
1. Sprite screenshot + shift-click wearables  
2. Inventory list (“She is wearing…”)  
3. Player flavor text (only for unseen details).  
If sources conflict, **trust the sprite** or ask the user.

---

### Security HUDSunglasses  (always Security)
**Sprite call-outs**  
- Chunky black, almost square frame.  
- Dark lenses with **red→orange diagonal HUD glare** (upper-inner quadrant).  
- Matte utilitarian finish; small black/grey earpieces.

**Prompt wording snippet**  
> “black security HUD sunglasses – dark lenses displaying a diagonal red-orange holographic HUD glow across each lens”

**Common pitfalls** → plain black shades • mirrored aviators • blue/green glare.

---

### Grey Cartridge ID Badge
**Sprite call-outs**  
- Rectangular grey cartridge, tiny red status light (bottom-right).  
- No readable text at default size.

**Prompt wording snippet**  
> “grey cartridge-style security ID badge with small red status light (no readable text)”
